# CLI Music

Консольный музыкальный плеер на Rust: поиск в YouTube Music, воспроизведение аудио, очередь и доступ к доступным вашему аккаунту видео и плейлистам. `mpv` использует `yt-dlp` для получения аудиопотока вместе с нужными HTTP-заголовками и cookies.

## Установка

Установите Python 3.10 или новее, [Rust](https://www.rust-lang.org/tools/install), [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) и [mpv](https://mpv.io/installation/). Исполняемые файлы `yt-dlp` и `mpv` должны быть доступны в PATH. После установки откройте новый терминал и проверьте `cargo --version`, `yt-dlp --version`, `mpv --version`.

В каталоге проекта установите библиотеку для поиска и текстов YouTube Music и соберите приложение:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cargo build --release
cargo run --release
```

В Windows используйте `python -m venv .venv` и `.venv\Scripts\python -m pip install -r requirements.txt`. При запуске из каталога проекта приложение находит `.venv` самостоятельно. При запуске из другой папки активируйте окружение или задайте `CLI_MUSIC_PYTHON` как полный путь к его интерпретатору.

Готовый исполняемый файл находится в `target/release/cli-music` (в Windows — `target\release\cli-music.exe`). Аудиоустройство и доступ к YouTube необходимы для воспроизведения.

## Вход

Для публичного поиска вход обычно не нужен. Чтобы использовать сессию Google при воспроизведении, войдите в YouTube в обычном браузере, запустите приложение, выйдите из поля поиска стрелкой вниз или Esc и нажмите **g**. Выберите браузер стрелками и нажмите Enter; выбор сохраняется в `~/.cli-music/browser`. Пароль Google в приложении вводить не нужно. Если YouTube запросил вход, после выбора браузера запустите трек снова.

Браузер можно также указать при запуске:

```sh
cargo run --release -- --browser firefox
```

Например, можно указать `chrome`, `edge` или `firefox`; подробности о профилях и поддерживаемых браузерах приведены в документации yt-dlp к `--cookies-from-browser`. На некоторых системах чтению cookies мешают блокировка профиля или системное хранилище ключей. Альтернатива — файл cookies в формате Netscape:

```sh
cargo run --release -- --cookies /путь/к/cookies.txt
```

Файл cookies даёт доступ к вашему аккаунту: храните его в безопасном месте и не добавляйте в репозиторий. Приложение не запрашивает пароль и передаёт настройки доступа непосредственно yt-dlp. Для личного плейлиста вставьте его ссылку в поле поиска.

## Использование

После запуска откроется полноэкранный интерфейс. Введите название или ссылку в поле поиска и нажмите Enter. Стрелками вниз переходите от поиска через результаты к кнопкам управления; стрелки вверх ведут обратно. В результатах каналы исполнителей показаны перед треками. Enter на исполнителе открывает его песни в YouTube Music. На экране видна часть списка; остальные результаты подгружаются при приближении к концу. Для исполнителя показывается список песен, доступный YouTube Music.

- **↑ / ↓** — переход между поиском, результатами и управлением; в списках — выбор трека. **← / →** — выбор кнопки. **Ctrl+↑ / Ctrl+↓** — сразу перейти к управлению. Мышью можно выбрать и запустить результат, нажать кнопки плеера и прокручивать списки или текст.
- **Enter** на треке — воспроизвести его и поставить последующие треки из списка в очередь. Клик мышью открывает меню: играть, играть следующим или добавить в очередь.
- **a** — добавить выбранный результат в очередь; **Shift+A** — добавить все результаты, например элементы плейлиста.
- **Tab** — открыть или закрыть окно очереди. В нём **↑ / ↓** выбирают трек, **d** или **Delete** удаляет его, **Esc** закрывает окно.
- **Пробел** — пауза или продолжение. На панели управления нажмите Enter или пробел на выбранной кнопке.
- **p / n** — предыдущий / следующий трек. При возврате предыдущий текущий трек сохраняется следующим в очереди. История действует в течение сеанса и очищается кнопкой «Стоп».
- **+ / -** — громкость; **s** — остановить и очистить очередь; **/** — поиск; **q** — выход. В поле поиска сначала нажмите Esc или стрелку вниз.
- **g** — выбрать браузер с активной сессией Google; **l** — открыть полный текст текущей песни, если он есть в YouTube Music (он также показывается под обложкой); **e** — показать сообщение об ошибке целиком.

Обложка текущего трека загружается в фоне через yt-dlp и сохраняется в `~/.cli-music/covers` (на Windows — в домашней папке пользователя). При повторном воспроизведении используется кеш; его можно удалить вручную. Обложка отображается цветными символами, поэтому нужен терминал с поддержкой цвета.

Под обложкой показаны уровни двадцати частотных полос воспроизводимого аудио. Анализатор использует аудиофильтры FFmpeg внутри mpv и не меняет звук. Если фильтры в сборке mpv недоступны, трек автоматически запустится без анализатора. На паузе индикатор обнуляется. На Windows анализатор и определение времени трека пока недоступны; воспроизведение работает без них.

Списки артистов и песен ищутся параллельно. Если за выбранным треком есть ещё не загруженные результаты, приложение запрашивает их в фоне и добавляет в очередь; если порядок результатов изменился, оно сообщает об этом. Когда воспроизводится песня, следующий трек YouTube Music с выбранными cookies заранее подготавливается в ограниченном буфере в памяти; при изменении очереди подготовка отменяется. Переход между треками зависит от сети и может занимать некоторое время. В плеере показаны время и сегментный индикатор, если mpv сообщает длительность потока.

Поиск и тексты используют неофициальную библиотеку `ytmusicapi`; публичный каталог работает отдельно от сессии Google в браузере. Вход через cookies не гарантирует, что YouTube не запросит дополнительную проверку. Для YouTube Music с выбранными cookies сначала используется клиент `tv_samsung` и загрузка частями по 64 КиБ через yt-dlp без сохранения трека в файл. Для остальных ссылок сначала используется обычный механизм mpv и yt-dlp. Если повтор не удался, приложение пробует другие доступные варианты, включая HLS с клиентом `web_safari`. Настройки cookies сохраняются при всех попытках; успех зависит от доступности формата и ограничений YouTube. Если попытки не удались, их ошибки доступны по клавише `e`. Поиск и получение потока зависят от YouTube и yt-dlp: ограничения доступа, география, возрастные ограничения и изменения YouTube могут препятствовать воспроизведению. Если возникла ошибка, нажмите `e` вне поля поиска, чтобы прочитать сообщение целиком. Проверка входа со стороны YouTube может сохраняться даже при действующих cookies; проверьте доступ к треку в выбранном браузере. При передаче сообщения другим людям удалите личные данные и ссылки на поток. Прямой аудиопоток обычно воспроизводится без рекламных вставок веб-плеера, но это не гарантируется для каждого видео и может измениться. Встроенные в саму запись рекламные фрагменты остаются.

Для воспроизведения некоторых треков YouTube Music может потребоваться PO Token. При одном из повторов для ссылок YouTube Music с выбранными cookies приложение использует клиент `web_music`; установленный провайдер PO Token может автоматически выдать ему токен. Установка и обновление внешнего провайдера описаны в [руководстве yt-dlp](https://github.com/yt-dlp/yt-dlp/wiki/PO-Token-Guide). Само приложение провайдер не устанавливает. Если формат недоступен, также пробуется HLS. Получение токена не гарантирует доступ ко всем трекам.

Проверка проекта: `cargo test` и `.venv/bin/python -m unittest discover -s tests`.
