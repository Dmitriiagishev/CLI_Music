# CLI Music

Консольный музыкальный плеер на Rust: поиск на YouTube, воспроизведение аудио, очередь и доступ к доступным вашему аккаунту видео и плейлистам. Аудиопоток получает `yt-dlp`, воспроизводит `mpv`.

## Установка

Установите [Rust](https://www.rust-lang.org/tools/install), [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) и [mpv](https://mpv.io/installation/). Исполняемые файлы `yt-dlp` и `mpv` должны быть доступны в PATH. После установки откройте новый терминал и проверьте `cargo --version`, `yt-dlp --version`, `mpv --version`.

В каталоге проекта выполните:

```sh
cargo build --release
cargo run --release
```

Готовый исполняемый файл находится в `target/release/cli-music` (в Windows — `target\release\cli-music.exe`). Аудиоустройство и доступ к YouTube необходимы для воспроизведения.

## Вход

Для публичных видео вход обычно не нужен. Для доступа к своему аккаунту сначала войдите в YouTube в браузере, а затем запустите приложение с именем браузера, поддерживаемым yt-dlp:

```sh
cargo run --release -- --browser firefox
```

Например, можно указать `chrome`, `edge` или `firefox`; подробности о профилях и поддерживаемых браузерах приведены в документации yt-dlp к `--cookies-from-browser`. На некоторых системах чтению cookies мешают блокировка профиля или системное хранилище ключей. Альтернатива — файл cookies в формате Netscape:

```sh
cargo run --release -- --cookies /путь/к/cookies.txt
```

Файл cookies даёт доступ к вашему аккаунту: храните его в безопасном месте и не добавляйте в репозиторий. Приложение не запрашивает пароль и передаёт настройки доступа непосредственно yt-dlp. Для личного плейлиста вставьте его ссылку в поле поиска.

## Использование

После запуска откроется полноэкранный интерфейс. Введите название или ссылку в поле поиска и нажмите Enter. Стрелками вниз переходите от поиска через результаты к кнопкам управления; стрелки вверх ведут обратно. В результатах каналы исполнителей показаны перед треками. Enter на исполнителе открывает его видео. Количество результатов зависит от высоты окна на момент поиска.

- **↑ / ↓** — переход между поиском, результатами и управлением; в списках — выбор трека. **← / →** — выбор кнопки.
- **Enter** на результате — сразу воспроизвести его и очистить прежнюю очередь.
- **a** — добавить выбранный результат в очередь; **Shift+A** — добавить все результаты, например элементы плейлиста.
- **Tab** — открыть или закрыть окно очереди. В нём **↑ / ↓** выбирают трек, **d** или **Delete** удаляет его, **Esc** закрывает окно.
- **Пробел** — пауза или продолжение. На панели управления нажмите Enter или пробел на выбранной кнопке.
- **p / n** — предыдущий / следующий трек. При возврате предыдущий текущий трек сохраняется следующим в очереди. История действует в течение сеанса и очищается кнопкой «Стоп».
- **+ / -** — громкость; **/** — вернуться к поиску; **q** — выход. В поле поиска сначала нажмите Esc или стрелку вниз.

Обложка текущего трека загружается в фоне через yt-dlp и сохраняется в `~/.cli-music/covers` (на Windows — в домашней папке пользователя). При повторном воспроизведении используется кеш; его можно удалить вручную. Обложка отображается цветными символами, поэтому нужен терминал с поддержкой цвета.

Под обложкой показаны уровни восьми частотных полос воспроизводимого аудио. Анализатор использует аудиофильтры FFmpeg внутри mpv и не меняет звук. Если фильтры в сборке mpv недоступны, трек автоматически запустится без анализатора. На паузе индикатор обнуляется. На Windows анализатор пока недоступен; воспроизведение работает без него.

Поиск и получение потока зависят от YouTube и yt-dlp: ограничения доступа, география, возрастные ограничения и изменения YouTube могут препятствовать воспроизведению. Если возникла ошибка, прочитайте сообщение в нижней части экрана, обновите yt-dlp и проверьте доступ к видео в браузере. Прямой аудиопоток обычно воспроизводится без рекламных вставок веб-плеера, но это не гарантируется для каждого видео и может измениться. Встроенные в саму запись рекламные фрагменты остаются.

Проверка проекта: `cargo test`.
