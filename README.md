# CLI Music

Консольный музыкальный плеер на Rust: поиск на YouTube, воспроизведение аудио, очередь и доступ к доступным вашему аккаунту видео и плейлистам. Аудиопоток получает `yt-dlp`, воспроизводит `mpv`.

## Установка

Установите [Rust](https://www.rust-lang.org/tools/install), [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) и [mpv](https://mpv.io/installation/). Исполняемые файлы `yt-dlp` и `mpv` должны быть доступны в PATH. После установки откройте новый терминал и проверьте `cargo --version`, `yt-dlp --version`, `mpv --version`.

В каталоге проекта выполните:

```sh
cargo build --release
cargo run --release
```

Готовый исполняемый файл находится в `target/release/cli-music` (в Windows — `target\release\cli-music.exe`). Аудиоустройство и доступ к YouTube необходимы для воспроизведения.

## Вход

Для публичных видео вход обычно не нужен. Для доступа к своему аккаунту сначала войдите в YouTube в браузере, а затем запустите приложение с именем браузера, поддерживаемым yt-dlp:

```sh
cargo run --release -- --browser firefox
```

Например, можно указать `chrome`, `edge` или `firefox`; подробности о профилях и поддерживаемых браузерах приведены в документации yt-dlp к `--cookies-from-browser`. На некоторых системах чтению cookies мешают блокировка профиля или системное хранилище ключей. Альтернатива — файл cookies в формате Netscape:

```sh
cargo run --release -- --cookies /путь/к/cookies.txt
```

Файл cookies даёт доступ к вашему аккаунту: храните его в безопасном месте и не добавляйте в репозиторий. Приложение не запрашивает пароль и передаёт настройки доступа непосредственно yt-dlp. Для личного плейлиста используйте его ссылку с командой `url`.

## Использование

Введите `help` в приложении. Пример:

```text
search Daft Punk One More Time
play 1
search любимый исполнитель
add 2
queue
pause
next
volume -10
quit
```

`url <ссылка>` добавляет видео или элементы плейлиста в очередь; `stop` останавливает воспроизведение и очищает очередь. Поиск и получение потока зависят от YouTube и yt-dlp: ограничения доступа, география, возрастные ограничения и изменения YouTube могут препятствовать воспроизведению. Если возникла ошибка, обновите yt-dlp и проверьте доступ к видео в браузере. Прямой аудиопоток обычно воспроизводится без рекламных вставок веб-плеера, но это не гарантируется для каждого видео и может измениться. Встроенные в саму запись рекламные фрагменты остаются.

Проверка проекта: `cargo test`.
